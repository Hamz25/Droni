# Body

The physical drone.

- bom/      the final parts list - model numbers, prices, where bought
- wiring/   wiring diagrams, so you know which wire goes where
- configs/  flight-controller and radio settings, saved so you never lose them

docs/hardware/2-architecture/adr/0001-off-the-shelf-hardware.md for why.
